# JSON Data Processor

A Python program that reads employee information from a JSON file and performs searching, filtering, and summary operations on it.

## Objective

Learn JSON handling and structured data processing in Python.

## Tools Used

- Python 3
- `json` module (standard library, no installation needed)

## Project Files

| File | Description |
|------|-------------|
| `employees.json` | JSON input file containing 10 employee records |
| `json_processor.py` | Python processing script |
| `results.json` | Filtered and summarized results (generated by the script) |
| `README.md` | Project documentation |

## Input Data Structure

Each employee record in `employees.json` contains:

```json
{
  "id": 101,
  "name": "Ali Raza",
  "department": "Engineering",
  "salary": 120000,
  "active": true,
  "skills": ["Python", "Django", "SQL"],
  "address": {"city": "Lahore", "country": "Pakistan"}
}
```

The file includes nested dictionaries (`address`) and lists (`skills`) to demonstrate handling of structured data.

## Features

### Searching
- Search employees by name (case-insensitive, partial match)

### Filtering
- By department
- By minimum salary
- By skill
- By city
- Active employees only

### Summary Operations
- Total number of employees
- Active and inactive count
- Total and average salary
- Highest and lowest paid employee
- Department-wise count and average salary

### Validation and Error Handling
- Checks that the input file exists
- Handles invalid JSON format
- Verifies the `employees` key exists and is a list
- Skips any record with missing required keys and reports it

## How to Run

1. Place `employees.json` and `json_processor.py` in the same folder.
2. Open a terminal in that folder.
3. Run:

```bash
python json_processor.py
```

The script prints all results on screen and saves them to `results.json`.

## Key Concepts

- `json.load()` reads JSON from a file into Python objects.
- `json.dump()` writes Python objects to a JSON file.
- JSON objects become Python dictionaries and JSON arrays become lists.
- JSON `true`, `false`, `null` become Python `True`, `False`, `None`.
- Nested data is accessed by chaining keys, for example `employee["address"]["city"]`.

## Interview Questions

**What is JSON?**
JSON (JavaScript Object Notation) is a lightweight, text-based format for storing and exchanging structured data. It is easy for humans to read and for machines to parse.

**What is the difference between JSON and a Python dictionary?**
JSON is a text format used for data exchange, and it only allows double-quoted string keys and values like `true`, `false`, `null`. A Python dictionary is an in-memory object that can use many key types and values like `True`, `False`, `None`. `json.loads()` and `json.dumps()` convert between the two.

**How do you read and write a JSON file in Python?**
Use `json.load(file)` to read and `json.dump(data, file)` to write.

**How do you validate that expected keys exist?**
Compare the required keys with the record's keys, for example `REQUIRED_KEYS - record.keys()`, and skip or report records with missing keys.
